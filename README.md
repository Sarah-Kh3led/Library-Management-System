# 📚 Library Management System (Console Application)

A simple and efficient Console-based Library Management System developed using C#. This project focuses on core programming concepts such as conditional statements (if-else), functions (methods), and structured user interaction to manage books within a library.

---

## 🛠️ Built With

* C# - Core programming language.
* Visual Studio - Development environment.
* Console Application - Text-based user interface.

---

## ✨ Features & Menu Options

The system provides an interactive menu with the following operations:
1. Add Book: Add a new book to the library system.
2. View All Books: Display a list of all available books.
3. Search Book: Find specific books in the system.
4. Delete Book: Remove a book from the library records.
5. Borrow Book: Manage book borrowing operations.
6. Return Book: Handle returned books.
7. Edit Book: Update existing book details.
8. Exit: Close the application.
